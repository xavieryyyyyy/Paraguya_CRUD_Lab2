# Application file map

Paths start inside `app-crud/`. Open a file from the links below; its header comments name the calling/related files.

## Workspace around the application

| Location | Purpose |
|---|---|
| app-crud/ | Laravel source; run Artisan/Composer/npm here |
| docs/START_HERE.md | Current learning-pack entry point |

| docs/COMPLETE_STUDY_GUIDE.md | Language concepts and request-flow explanations |

## Active source and generated scaffold

Read entry points and routes first, then controllers/requests/models, then views and assets. The alphabetical groups below let you locate a specific file afterward.

## Application root

### .editorconfig

[Open source](../app-crud/.editorconfig)

Editor spacing, line endings, and charset preferences. Applies to editor formatting, not controller runtime behavior.

### .env.example

[Open source](../app-crud/.env.example)

Shareable environment template with empty/default values. Copy locally to .env and supply private values. It is not the current secret configuration.

### .gitattributes

[Open source](../app-crud/.gitattributes)

Git text/diff settings for the Laravel source. Line-ending rules explain CRLF/LF conversion messages when saving on Windows.

### .gitignore

[Open source](../app-crud/.gitignore)

Laravel excludes env/dependency/runtime artifacts. The workspace root ignore file additionally excludes agent/PDF preparation folders and local database files.

### README.md

[Open source](../app-crud/README.md)

Links to the current learning pack and workspace setup instructions, followed by the retained generated Laravel framework README.

### artisan

[Open source](../app-crud/artisan)

Terminal entry point. PHP loads the same application bootstrap used by web requests, but handles an Artisan command such as serve, migrate, or route:list instead of returning a browser page.

### composer.json

[Open source](../app-crud/composer.json)

PHP package requirements and Composer scripts. The require sections choose Laravel/Breeze/tools; scripts run setup/test/discovery steps. JSON cannot contain comments.

### composer.lock

[Open source](../app-crud/composer.lock)

Exact PHP dependency versions resolved by Composer. Commit it for repeatable installation; do not annotate or manually edit its package records.

### package-lock.json

[Open source](../app-crud/package-lock.json)

Exact resolved Node dependency versions used by npm. Generated by npm and kept in Git; not a source file for manual teaching comments.

### package.json

[Open source](../app-crud/package.json)

Node package requirements and npm scripts. build runs Vite build and dev runs the Vite development server. JSON cannot contain comments.

### phpunit.xml

[Open source](../app-crud/phpunit.xml)

PHPUnit suites/source scope and testing environment. SQLite :memory:, array sessions/cache/mail, and lower test hashing cost isolate tests from real database/email.

### postcss.config.js

[Open source](../app-crud/postcss.config.js)

Build pipeline loads Tailwind and Autoprefixer for generated CSS. This file is read by tooling, not by the browser as a script.

### tailwind.config.js

[Open source](../app-crud/tailwind.config.js)

Tailwind scans Blade files for utility classes, includes its forms plugin, and defines scaffold fonts. The custom plain stylesheet separately selects Inter on auth/product pages.

### vite.config.js

[Open source](../app-crud/vite.config.js)

Vite registers CSS/JavaScript entry files with the Laravel plugin and refreshes development pages. npm run build creates public/build/manifest.json used by the vite directive.

## app

### app/Http/Controllers/Auth/AuthenticatedSessionController.php

[Open source](../app-crud/app/Http/Controllers/Auth/AuthenticatedSessionController.php)

Login/logout controller called from routes/auth.php. LoginRequest validates credentials; successful login regenerates the session and returns to the intended page or Products. Logout clears the session and returns to Login.

Methods to locate: `create()`, `store()`, `destroy()`.

### app/Http/Controllers/Auth/ConfirmablePasswordController.php

[Open source](../app-crud/app/Http/Controllers/Auth/ConfirmablePasswordController.php)

Password confirmation for a signed-in user. Verifies the current password and records confirmation time in the session. It does not change the password or automatically protect every product action.

Methods to locate: `show()`, `store()`.

### app/Http/Controllers/Auth/EmailVerificationNotificationController.php

[Open source](../app-crud/app/Http/Controllers/Auth/EmailVerificationNotificationController.php)

Resends a verification notification for the signed-in user. routes/auth.php limits these requests. This generated feature is separate from the tested password-reset email flow.

Methods to locate: `store()`.

### app/Http/Controllers/Auth/EmailVerificationPromptController.php

[Open source](../app-crud/app/Http/Controllers/Auth/EmailVerificationPromptController.php)

Invokable controller for the verification notice. Shows auth.verify-email when needed. Routes exist, but full verification enforcement requires User to implement MustVerifyEmail.

Methods to locate: `__invoke()`.

### app/Http/Controllers/Auth/NewPasswordController.php

[Open source](../app-crud/app/Http/Controllers/Auth/NewPasswordController.php)

Reset Password controller. The email link supplies a token and email to the view. The POST handler validates input, asks the password broker to verify the token, hashes the new password, and returns to Login with feedback.

Methods to locate: `create()`, `store()`.

### app/Http/Controllers/Auth/PasswordController.php

[Open source](../app-crud/app/Http/Controllers/Auth/PasswordController.php)

Authenticated profile-password update. The profile partial submits current_password and the new password here. This flow requires the current password and does not use an emailed reset token.

Methods to locate: `update()`.

### app/Http/Controllers/Auth/PasswordResetLinkController.php

[Open source](../app-crud/app/Http/Controllers/Auth/PasswordResetLinkController.php)

Forgot Password controller for password.request/password.email routes. The view collects an email; the password broker creates a reset token and sends a notification through config/mail.php. No password is changed at this stage.

Methods to locate: `create()`, `store()`.

### app/Http/Controllers/Auth/RegisteredUserController.php

[Open source](../app-crud/app/Http/Controllers/Auth/RegisteredUserController.php)

Registration controller for GET/POST register. Validates account details, creates a User with a password hash, fires Registered, signs in that user, then redirects to Dashboard. Registration currently has a different default destination from login.

Methods to locate: `create()`, `store()`.

### app/Http/Controllers/Auth/VerifyEmailController.php

[Open source](../app-crud/app/Http/Controllers/Auth/VerifyEmailController.php)

Handles signed verification URLs, marks the signed-in user email verified, and fires Verified. Laravel validates the request signature and route identity before this controller runs.

Methods to locate: `__invoke()`.

### app/Http/Controllers/Controller.php

[Open source](../app-crud/app/Http/Controllers/Controller.php)

Shared parent of the application controllers. Concrete controllers contain the request methods; this empty abstract class keeps a common place for future shared behavior.

### app/Http/Controllers/ProductController.php

[Open source](../app-crud/app/Http/Controllers/ProductController.php)

CRUD coordinator called by the six protected product routes in routes/web.php. Reads and validates input, calls the Product model, then returns a products view or a redirect with success feedback.

Methods to locate: `index()`, `create()`, `store()`, `edit()`, `update()`, `destroy()`.

### app/Http/Controllers/ProfileController.php

[Open source](../app-crud/app/Http/Controllers/ProfileController.php)

Generated Breeze profile actions: display the current user, update profile details, or delete the account after current-password validation. Product records have no user_id relationship, so deleting an account does not cascade-delete products.

Methods to locate: `edit()`, `update()`, `destroy()`.

### app/Http/Requests/Auth/LoginRequest.php

[Open source](../app-crud/app/Http/Requests/Auth/LoginRequest.php)

Login-specific validation object injected into AuthenticatedSessionController::store(). Checks input, limits failed login attempts, and asks the web guard to authenticate using the remember checkbox value.

Methods to locate: `authorize()`, `rules()`, `authenticate()`, `ensureIsNotRateLimited()`, `throttleKey()`.

### app/Http/Requests/ProfileUpdateRequest.php

[Open source](../app-crud/app/Http/Requests/ProfileUpdateRequest.php)

Rules for profile name/email changes. The unique-email rule ignores the current user ID so keeping the same email is allowed while taking another user email is rejected.

Methods to locate: `rules()`.

### app/Models/Product.php

[Open source](../app-crud/app/Models/Product.php)

Product model for the products table. ProductController uses all(), create(), update(), and delete() inherited from Eloquent. The products migration defines columns; this model works with the rows.

### app/Models/User.php

[Open source](../app-crud/app/Models/User.php)

User model for the users table. Authentication uses this class to load accounts. HasFactory creates test users; Notifiable sends reset/verification notifications. Email verification is not enforced because this class does not implement MustVerifyEmail.

Methods to locate: `casts()`.

### app/Providers/AppServiceProvider.php

[Open source](../app-crud/app/Providers/AppServiceProvider.php)

Startup extension point registered in bootstrap/providers.php. register() can bind services; boot() runs after registration. Both are empty here because the labs use Laravel defaults.

Methods to locate: `register()`, `boot()`.

### app/View/Components/AppLayout.php

[Open source](../app-crud/app/View/Components/AppLayout.php)

Class component behind x-app-layout on Dashboard/Profile. render() selects layouts.app, where component content is supplied as $slot.

Methods to locate: `render()`.

### app/View/Components/GuestLayout.php

[Open source](../app-crud/app/View/Components/GuestLayout.php)

Class component behind x-guest-layout. render() selects layouts.guest, which wraps Login/Register/Forgot/Reset pages and loads the custom auth styles.

Methods to locate: `render()`.

## bootstrap

### bootstrap/app.php

[Open source](../app-crud/bootstrap/app.php)

Application setup. Registers routes/web.php, routes/console.php, and the health endpoint. Laravel supplies its default middleware; named auth/guest middleware is applied in the route files.

### bootstrap/providers.php

[Open source](../app-crud/bootstrap/providers.php)

Lists application service providers loaded during startup. AppServiceProvider supplies application-wide registration and boot hooks.

## config

### config/app.php

[Open source](../app-crud/config/app.php)

Application name, URL, locale, key, timezone, and general settings. env() reads deployment values; never copy the real key into a public explanation.

### config/auth.php

[Open source](../app-crud/config/auth.php)

Session web guard, Eloquent User provider, and password broker settings. Reset expiry is in minutes; throttle is in seconds. Role/admin checks are not defined here.

### config/cache.php

[Open source](../app-crud/config/cache.php)

Cache stores and prefix. Laravel rate limiting can use the configured store; clearing cache is different from deleting product records.

### config/database.php

[Open source](../app-crud/config/database.php)

Database connections and migration/cache configuration. .env selects the mysql connection to XAMPP MariaDB; tests use isolated in-memory SQLite.

### config/filesystems.php

[Open source](../app-crud/config/filesystems.php)

Storage disks, paths, and public-storage link definitions. Does not define product database columns or permissions.

### config/logging.php

[Open source](../app-crud/config/logging.php)

Log channels and destinations for application events/errors. Runtime logs may include private details and are excluded from Git.

### config/mail.php

[Open source](../app-crud/config/mail.php)

Mailer definitions and sender defaults. smtp uses MAIL_SCHEME/HOST/PORT/USERNAME/PASSWORD. The password broker notification reaches this mailer; keep real credentials in .env only.

### config/queue.php

[Open source](../app-crud/config/queue.php)

Queue connections and failed-job settings. Tables exist for optional background jobs; a queue worker is only needed when work is explicitly queued.

### config/services.php

[Open source](../app-crud/config/services.php)

Optional third-party integration settings. The current reset email uses SMTP config rather than these optional service transports.

### config/session.php

[Open source](../app-crud/config/session.php)

Session driver, lifetime, cookie, and related options. Database sessions connect browser requests to authenticated users through the sessions table.

## database

### database/factories/UserFactory.php

[Open source](../app-crud/database/factories/UserFactory.php)

Creates fake User data for tests. Factory users are test fixtures; fake values do not register real users or send real email during the test suite.

Methods to locate: `definition()`, `unverified()`.

### database/migrations/0001_01_01_000000_create_users_table.php

[Open source](../app-crud/database/migrations/0001_01_01_000000_create_users_table.php)

Creates users, password_reset_tokens, and sessions. User/auth controllers use users; the password broker uses reset tokens; the configured database session driver uses sessions.

Methods to locate: `up()`, `down()`.

### database/migrations/0001_01_01_000001_create_cache_table.php

[Open source](../app-crud/database/migrations/0001_01_01_000001_create_cache_table.php)

Creates database cache/lock tables. Laravel can use these for cached values and rate limiting when the configured cache store is database.

Methods to locate: `up()`, `down()`.

### database/migrations/0001_01_01_000002_create_jobs_table.php

[Open source](../app-crud/database/migrations/0001_01_01_000002_create_jobs_table.php)

Creates queued-job, batch, and failed-job tables. These support background jobs; our reset notification is sent synchronously in the current flow.

Methods to locate: `up()`, `down()`.

### database/migrations/2026_10_07_015613_create_products_table.php

[Open source](../app-crud/database/migrations/2026_10_07_015613_create_products_table.php)

Creates products for the Product model. up() defines columns; down() drops the whole table on rollback. A migration changes structure; it does not submit product form values.

Methods to locate: `up()`, `down()`.

### database/seeders/DatabaseSeeder.php

[Open source](../app-crud/database/seeders/DatabaseSeeder.php)

Optional sample-data entry point for db:seed. Do not run it just to view the application; normal registration and product forms create records through controllers.

Methods to locate: `run()`.

## public

### public/.htaccess

[Open source](../app-crud/public/.htaccess)

Apache rewrite rules that direct application URLs to public/index.php. Artisan serve uses its own development routing, so this Apache file is not the primary server in our tests.

### public/css/auth.css

[Open source](../app-crud/public/css/auth.css)

Authentication-specific styles loaded after style.css. Centers guest forms, handles field icons/Show-Hide controls, checkbox layout, errors, and contrasting primary buttons in both themes.

### public/css/style.css

[Open source](../app-crud/public/css/style.css)

Shared product/glass theme styling. Product layout and guest layout load this URL directly. Controls Inter, backgrounds, buttons, table/forms, icons, keyboard focus, and the light-theme overrides.

### public/favicon.ico

[Open source](../app-crud/public/favicon.ico)

Browser-tab icon asset. Binary files have no comment syntax; this retained scaffold asset does not implement authentication.

### public/index.php

[Open source](../app-crud/public/index.php)

HTTP entry point. The browser request reaches this file, which loads Composer classes and bootstrap/app.php, then gives the captured request to Laravel. Routes select the next controller; this file does not perform CRUD itself.

### public/js/password-visibility.js

[Open source](../app-crud/public/js/password-visibility.js)

Adds a separate Show/Hide button to each styled password input. Changes the input type in the browser without changing its value, field name, authentication, or hashing.

### public/js/product-messages.js

[Open source](../app-crud/public/js/product-messages.js)

Removes only the product success banner after five seconds. The controller already completed the database operation before the list page and this timer appear.

### public/js/theme.js

[Open source](../app-crud/public/js/theme.js)

Appearance-only code loaded with defer by product/guest layouts. A click toggles light-theme on body and saves the browser choice in localStorage; it does not change account permissions.

### public/robots.txt

[Open source](../app-crud/public/robots.txt)

Crawler guidance only. It is not login protection and does not prevent access to a known URL; auth middleware protects product routes.

## routes

### routes/auth.php

[Open source](../app-crud/routes/auth.php)

Breeze URL map. guest protects registration/login/password-recovery pages from signed-in users. auth protects logout/profile-password/verification routes. GET displays forms; POST/PUT processes changes.

### routes/console.php

[Open source](../app-crud/routes/console.php)

Artisan command routes, not browser routes. The sample inspire command is generated scaffold and does not participate in the product or login flows.

### routes/web.php

## Excluded runtime and third-party folders

| Location | Meaning |
|---|---|
| vendor/ | Composer-installed Laravel/Symfony/PHPUnit and other package code |
| node_modules/ | npm-installed frontend/build packages |
| public/build/ | Vite compiled CSS/JS and manifest; regenerate using npm run build |
| bootstrap/cache/ | Generated framework cache files; keep the provided ignore file |
| storage/framework/views/ | Compiled Blade PHP; edit the original Blade source instead |
| storage/framework/sessions/ | File-session runtime location when that driver is selected |
| storage/logs/ | Runtime logs, potentially containing private details |
| storage/app/ | Application file storage; not the MySQL product table |

The root .env is not versioned. Runtime folders retain ignore files so required directory structure can exist after cloning.

## Reading one file without getting lost

Find its route/caller, read the method signature, follow its input checks, identify any data-changing call, and identify the returned response. For a view, identify its layout, required variables, form action/method, field names, and feedback blocks. For a script, identify its selector and event/timer. Use the complete guide for syntax explanations.
